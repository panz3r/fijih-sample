# S16. Resume from another session or a linked worktree

Any scenario works; S1 is the simplest.

## Precondition

- `scripts/reset`

## Run

1. Run until `local-qa-review` is presented, then stop the session.

### (a) New session

1. Start a new session and run the same command. **Expect:** routing from `lifecycle.checkpoint` and `lifecycle.transition`, not from chat.

### (b) Linked worktree

1. `git worktree add ../fijih-sample-wt <branch>` and run from there. **Expect:** the main checkout's `AI-MODELS.md` is read and held commits are reported.

## Reset

- `git worktree remove ../fijih-sample-wt`
- `scripts/reset`
