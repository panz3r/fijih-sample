# S12. `fiji-setup-project` from a bare repository

Project setup and convention inference on a repository without FIJIₕ conventions. No Jira issue is involved.

## Precondition

- `git checkout -b setup-trial bare` (no `AGENTS.md`, `TEAMS.md`, `AI-MODELS.md`, `CODEOWNERS`)

## Run

1. `/fiji-setup-project`. **Expect:** an install of the FIJIₕ version named, the environment report, and conventions inferred from the repository (Conventional Commits from the two commits, and the CI commands) with the owning team as the one blocking gap; the proposal is one diff per file, written only after approval.
2. Compare the proposal with the committed `AGENTS.md` on `baseline`.

## Reset

- `git checkout main && git branch -D setup-trial`
