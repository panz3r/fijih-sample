# S22. Source drift after Local QA review

The issue changes in Jira while `local-qa-review` is pending. Unlike S14, the run is not suspended: the change is shown at the next checkpoint, and you choose for each difference whether to adopt it now, keep it as a follow-up, or leave it out.

## Precondition

- `scripts/reset`

## Run

1. Approve `plan-approval` with a plain approval, without granting Publish or Notify. **Expect:** Local QA review ends at `local-qa-review`.
2. While `local-qa-review` is pending, edit the issue in Jira: change the tag length limit from 32 to 24, and add a comment that asks for nothing in this change, for example "Could the tags also be included in a future CSV export?".
3. Approve `local-qa-review`. **Expect:** the approval is acted on. Delivery pushes and opens the draft pull request, and the Copilot pass runs. Then `ready-for-review` shows a **Jira changed since <revision>** block under Questions: the limit change as `conflicting`, with the answers adopt now, keep as a follow-up, and leave out; and the comment as `editorial`, needing no answer.

### (a) Keep

4. Approve, answering "keep the 24-character limit as a follow-up". **Expect:** one work-item commit with `Late drift decision (ready-for-review)`, `Late drift kept:`, and `Late drift adopted:` Change Log entries and the new `source.revision`, and no `lifecycle` change. The pull request is then marked ready.
5. `scripts/review-as-qa <pr> approve`, then run the orchestrate command again. **Expect:** the `jira-handoff` draft lists the 24-character limit as a follow-up not filed yet, and the drift is not shown again, either at `jira-handoff` or after Cleanup.

### (b) Adopt now

4. Approve, answering "adopt the 24-character limit now". **Expect:** the approval is not acted on, so the pull request stays draft. Instead, a `Late drift decision (ready-for-review)` commit reopens AC 2 with an unchecked task, and Implementation re-enters with a `Re-entry: user-request` entry. Local QA review runs again.
5. **Expect:** the code and tests now use 24, and `ready-for-review` is presented again with no drift block.

## Reset

- `scripts/reset`
