# S8. Scope changes at `local-qa-review`

The three scope-change kinds, one per run, each answered at the `local-qa-review` checkpoint.

## Precondition

- `scripts/reset` before each run

## Run

1. **Narrowing.** Answer "approve, but drop the whitespace rule: a tag may contain spaces". **Expect:** a Scope record by `fiji-finalize-work-item` (the evidence already meets the relaxed wording only if the implementation never rejected spaces; otherwise the writer returns blocked and the change is routed again as Inline), then the same checkpoint again, with no QA re-run.
2. **Inline.** Answer "also trim tags to 24 characters". **Expect:** an Implementation re-entry with reason `user-request`, `attempt` 2, then Local QA review again.
3. **Full.** Answer "add a criterion that the bundle does not grow, measured by ci / measure". **Expect:** a Plan amendment and a new `plan-approval`.

## Reset

- `scripts/reset` between runs and at the end
