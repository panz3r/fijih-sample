# S4. Measurement problem

## Jira issue

Same as S2.

## Precondition

`scripts/reset`, then on `main` set `measure/baseline.json` to a value far below the real size (for example 100) and push it (admin bypass), so every delta on the branch is unmet for a reason unrelated to the change.

## Expected checkpoints

Delivery records `AC-3: ci-unmet — <delta> (run <id> on <sha>) — measurement: baseline on main is stale` and returns `blocked` with a question on the criterion instead of `ci-unmet`. Answering "relax to the measured value" is a Narrowing; "fix the baseline in this work item" is a Full change (the task changes how it is measured). No `ci-fail` re-entry, no fix round used.

## Reset

`scripts/reset` restores the baseline file.
