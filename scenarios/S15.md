# S15. Preflight blocks

Two environments Preflight must refuse: no remote, and no `jq`.

## Precondition

- `scripts/reset`

## Run

### (a) No remote

1. `git remote rename origin backup`, then start the run. **Expect:** Plan, Implementation, and Local QA review proceed, and the Local QA review checkpoint names the missing remote as a Delivery blocker.

### (b) No `jq`

1. Start the run with a `PATH` that has no `jq`. **Expect:** every phase blocked by the `validate-phase-result --check` failure.

## Reset

- `git remote rename backup origin`
- `scripts/reset`
